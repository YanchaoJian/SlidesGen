【主题名称】学术商务蓝

【整体氛围】专业、严谨、现代学术风，适合技术汇报和组会展示。

【色彩系统】
- 主色调：
  - 深蓝 #1E3A5F（标题和按钮背景）
  - 浅灰 #F0F0F0（主背景）

- 辅助色：
  - 中灰 #D1D5DB（内容背景）

- 文字色：
  - 深色文字：#333333（主正文）、#666666（次要文字）
  - 浅色文字：#FFFFFF（用于深色背景）

- 背景色：
  - 主背景：#F0F0F0
  - 内容区背景：#D1D5DB

【字体规范】
- 标题：微软雅黑 + Arial，32pt，Bold，#1E3A5F
- 正文：微软雅黑 + Arial，20pt（标题）/ 16pt（正文），Regular，#333333
- 特殊：按钮文字，微软雅黑 + Arial，16pt，Bold，#FFFFFF

【视觉特征】
- 几何风格：圆角矩形，现代简约
- 阴影效果：无阴影
- 线条：无明显线条
- 渐变：以纯色块为主

【布局原则】
- 顶部标题区：占屏幕 20%，深蓝背景，文字居中
- 内容区：占屏幕 60%，浅灰背景，左对齐
- 底部区域：占屏幕 20%，浅灰背景，右下角日期显示
- 文字层级：左对齐为主，标题居中

【组件特征】
- 文本框：无填充，边框无，文字左对齐
- 信息卡片：深蓝填充，白色文字
- 按钮：深蓝填充，白色文字，圆角设计
