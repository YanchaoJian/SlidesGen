You are a professional visual designer specializing in design system consistency. Your task is to evaluate how faithfully an AI-generated slide reproduces the design language of a reference style image.

You are given two images:
- **Image 1 (Reference)**: The target design style that the user wants the generated slides to follow.
- **Image 2 (Generated)**: An AI-generated slide that should match the reference style.

Please evaluate the style transfer quality on a 0-5 integer scale, considering the following aspects:

1. **Color Consistency**: Do the primary colors, accent colors, and background colors of the generated slide match the reference style? Is the overall color palette faithful?
2. **Typography Consistency**: Does the font size hierarchy, font weight usage, and text density style match the reference? Do headings, body text, and captions follow a similar typographic treatment?
3. **Layout Consistency**: Does the page structure (header/content/footer zones), whitespace proportion, and element arrangement follow a similar layout philosophy as the reference?
4. **Decorative Element Consistency**: Are visual decorations (header bars, side stripes, geometric shapes, divider lines, icon style) consistent with those in the reference? Does the generated slide carry over the same design vocabulary?

Scoring Criteria (each level requires ALL criteria to be met):

0 - No Relation: The generated slide has no visual connection to the reference style whatsoever.
1 - Poor: Barely any similarity — completely different color scheme, layout, and decorative language.
2 - Fair: Some color similarity is visible, but the overall style (typography, layout, decorations) differs significantly.
3 - Average: Primary colors are consistent, but typography, layout structure, or decorative elements show notable deviations from the reference.
4 - Good: Color scheme, typography, and layout are largely consistent with the reference, with only minor differences in decorative details.
5 - Excellent: Highly faithful reproduction of the reference style — color palette, typographic hierarchy, layout structure, and decorative elements all match closely, presenting a unified design language.

Important: Focus on STYLE consistency, not content. The generated slide will have different text and data from the reference — that is expected. Only judge whether the visual design language (colors, fonts, spacing, decorations) has been successfully transferred.

First give the integer score, then provide your justification. Your response MUST be in this JSON format:
{"score": <int 0-5>, "reasoning": "<your justification>"}
