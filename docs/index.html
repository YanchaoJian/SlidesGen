Features

Everything you need, out of the box

From raw PDF to pixel-perfect slides — each step powered by agents that reason, critique, and retry.

📄

Deep PDF understanding

Layout, OCR, equations, and tables extracted via Marker — so figures and formulas survive the journey.

🎨

Visual style transfer

Drop in any reference image. The style analyst agent distills it into a reusable protocol applied across every slide.

🧠

Multi-agent planning

Outline → per-slide layout → SVG code. Each phase is a specialized agent with its own prompts and critic.

🔁

Self-correcting loops

Unified retry budget covers style protocol, SVG validation, and CRAP design critique. Failures trigger rewrites, not crashes.

⚡

Parallel generation

Every slide runs as an independent LangGraph subgraph. A 20-slide deck finishes in the time of one.

👤

Human-in-the-loop

Two interrupt checkpoints let you approve the outline and the final deck — local edits or full regen, your call.

💾

Resumable sessions

SQLite-checkpointed via AsyncSqliteSaver. Kill the process, resume tomorrow from the exact same state.

🎯

Multi-model routing

Pick a vision model for style, a strong coder for SVG, and a fast text model for planning — each stage independently.

📊

Truly editable PPTX

Deterministic SVG → DrawingML conversion produces native PowerPoint shapes you can still move, recolor, and rewrite.

📝

Auto speaker notes

Each slide gets presenter notes generated from the paper content — ready for rehearsal right out of the box.

🔬

Built-in evaluation

LLM-as-Judge scores on content, design, and style transfer (0-5) plus HSV histogram similarity — all from the CLI.

Architecture

Two pipelines. One graph.

Style analysis and content extraction run in parallel, then converge on a fan-out slide generator. Each slide is its own subgraph.

01

👁 Perception

PDF parsing via marker-pdf + visual style analysis from a reference image.

02

📋 Planning

Outline generation, then per-slide layout expansion with detailed structural hints.

03

🎨 Execution

SVG generation → CRAP optimization → design critique, with a shared retry budget.

04

📤 Delivery

Feedback analyzer classifies user edits as local, global_style, or global_plan.

05

🔧 Pipeline

SVG validation, finalization, and deterministic SVG → DrawingML conversion.

Quick Start

Ready in three commands.

Python 3.11+, a PDF, a style image, and you're off. SlidesGen handles the rest.

install
$ conda create -n slides-gen python=3.11
$ pip install -r requirements.txt
$ python main.py --pdf_path paper.pdf \
    --style_image_path style.png
